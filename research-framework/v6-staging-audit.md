## Commercial acceptance criteria

Start with the product teams' objective for their next shared AI platform release. With the Head of AI or GenAI Platform Engineering Lead, establish what V1 delivers, what remains undecided, which controls are reusable, and which financial intelligence must remain proprietary. Ask what would make maintaining their gateway preferable to using a managed component. Confirm VP Engineering ownership independently. Then qualify execution state, isolation and locality for one agent workload. With security engineering, map external API and MCP traffic to existing token and authorisation controls before looking for an uncovered risk. No evidence establishes a live procurement cycle.
